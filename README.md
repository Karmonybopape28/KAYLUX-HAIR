# KAYLUX-HAIR
## part 1
Pages Created:
Home (Home.html): The landing page featuring a hero banner, company value pillars, and a product showcase grid.
About (About.html): Information about the brand's mission, vision, and why customers should choose KAYLUX.
Shop (Shop.html): The product catalogue page displaying premium wigs with prices and view details links.
Contact (Contact.html): Business hours, email support, phone numbers, and social media links.
FAQs (FAQs.html): Frequently asked questions regarding shipping, hair care quality, and return policies.

Key HTML Features:
Used modern semantic HTML5 tags (<header>, <nav>, <main>, <section>, <footer>) to ensure a proper document outline.
Implemented structured navigation menus with consistent headers and footers across all pages.
Created organized content layouts using headings (H1, H2, H3), lists, and paragraphs.
Added descriptive alt attributes to all images to improve web accessibility.

## Part 2: CSS Styling & Responsive Design

### Learning Outcomes Achieved:
- Created an external CSS stylesheet (style.css) to style the website.
- Applied decorative and typographic selectors (Google Fonts: Playfair Display & Montserrat).
- Built layout structures using CSS Flexbox and CSS Grid.
- Implemented Responsive Design using relative units (rem, %), responsive images, and media queries.
- Tested and iterated the design across Desktop, Tablet, and Mobile screen sizes.
